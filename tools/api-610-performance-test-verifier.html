§Notes & Conventions

  1. Test speed. Per API 610 11th Ed. Sec. 8.3.3.3, unless otherwise agreed the test speed shall be within 3% of the rated speed shown on the pump datasheet. Test results shall be corrected to rated speed. Any point outside that band is flagged red in the data table.
  2. Test fluid. Testing fluid for API pumps is water by default — use SPGRt = 1.0.
  3. Speed correction. The affinity laws are applied to every point: Q ∝ N, H ∝ N², P ∝ N³. Shaft power is then scaled by SPGRa so the result is the power the pump will draw on the actual process liquid.
  4. Datum elevation. This is the elevation to which NPSH values are referred. Use a positive value if the source is above the pump centreline, negative if below. If not specified, use 0 for both gauges.
  5. Test loop pipe size. If suction and discharge pipe sizes are not recorded, enter 1 for both — the two velocity heads then cancel and the differential velocity head ΔVh becomes zero, which is the correct assumption for equal-bore piping.
  6. Pipe schedule. See Appendix I for inside diameters, or measure the actual test-loop bore.
  7. Acceptance. See Appendix II for the Table 16 tolerances applied. The purchase order governs where it is more onerous than the standard.
  8. Specific-gravity handling. Differential head is derived from the measured differential pressure using the test fluid SG, and is then corrected for speed only — head is a property of the pump, not of the liquid, so it is not scaled by SPGRa. Hydraulic and shaft power are both scaled by SPGRa, which leaves efficiency independent of specific gravity as it must be. With water on both sides (SPGRt = SPGRa = 1) the results are identical to the source calculation sheet.
Scope. This verifier covers the Table 16 performance tolerances on head, power and efficiency. It does not evaluate NPSH testing, vibration acceptance, mechanical running test criteria, or the four-point curve shape requirements — those remain separate acceptance items on the shop test.
